# AI Agents (MCP)

`opera mcp` is a pure-Rust [Model Context Protocol](https://modelcontextprotocol.io) server over standard input and output for Claude Code, Claude Desktop, Cursor, and VS Code.

## Setup

```sh
# Using the standalone opera binary
claude mcp add opera -- opera mcp

# Or zero-install via uvx
claude mcp add opera -- uvx --from opera-rs opera mcp
```
